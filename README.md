# 🚀 Todo List Web Application

A modern, full-stack Todo List web application built with **Python Flask** backend and **vanilla JavaScript** frontend, fully containerized with **Docker** and automated with **CI/CD pipeline**.

## 🌟 Features

### 🎯 Core Functionality
- ✅ **Add, edit, and delete** todos
- ✅ **Mark tasks as complete/incomplete**
- ✅ **Filter tasks** (All, Active, Completed)
- ✅ **Clear completed tasks** in one click
- ✅ **Real-time task statistics**
- ✅ **Responsive design** for all devices

### 🛠 Technical Features
- 🐳 **Full Docker containerization**
- 🔄 **RESTful API architecture**
- 🎨 **Modern UI with CSS gradients**
- 📱 **Mobile-first responsive design**
- 🔧 **Health check endpoints**
- 🚀 **CI/CD pipeline with GitHub Actions**
